# Text-to-Speech Converter 🎙️

A simple and interactive **Text-to-Speech Converter** built using HTML, CSS, and JavaScript. This project converts written text into speech directly in the browser, providing an easy way to listen to any text.

## ✨ Features

- **Text Input:** Enter any text in the text area.
- **Voice Selection:** Choose an available voice from the voice selection dropdown.
- **Speak:** Convert written text into speech.
- **Pause:** Pause the speech while it is playing.
- **Stop:** Stop the current speech.
- **Simple UI:** Clean interface with a dark blue background.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Speech API
